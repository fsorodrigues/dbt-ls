# dbt LSP

dbt's language server protocol is proprietary and they say they have no plans to make it available outside of VSCode (ugh!), so I decided to experiment with building one from the ground up.

At this stage, it will offer very minimal functionality. I'm aiming at the basics of providing completion for model names and field names. I don't intend to "attack" SQL syntax at this stage or do anything particularly fancy. Maybe one day.
